# INC-133 — log-shipper OOM-killed every few hours

Log delivery had gaps of up to 20 minutes across the fleet for four hours.

## Timeline
- 14:00 alert: log-shipper restarts
- 16:10 heap profile shows failed batches retained
- 18:30 hotfix rolled out, incident closed

## Contributing factors
A memory leak in the log-shipper batching code retained failed batches indefinitely, growing the heap until the process was killed.

## Action taken
Rolled back to the previous log-shipper release.

## Follow-up
Permanent fix in [[REM-52]].
