# INC-147 — DNS query storm after resolver change

Intermittent name resolution failures.

## Timeline
- 10:15 alert fired
- 11:00 restored, incident closed

## Contributing factors
A resolver config change set the cache TTL to zero, so every lookup went upstream and coredns ran out of CPU.

## Action taken
Restored a 30-second TTL.
