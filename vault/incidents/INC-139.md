# INC-139 — Query cache stampede after deploy

Search latency spike after deploy.

## Timeline
- 12:00 alert fired
- 12:35 restored, incident closed

## Contributing factors
The deploy flushed every cached query key at once; thousands of identical cold queries hit the backend simultaneously because there was no request coalescing.

## Action taken
Added request coalescing and staggered key expiry.
