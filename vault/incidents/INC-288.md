# INC-288 — Gateway health checks flapping under load

The API gateway ejected healthy nodes for 75 minutes. Partial outage for all services behind it.

## Timeline
- 22:40 alert: gateway healthy-node count below 50%
- 22:52 probes time out on their database check
- 23:20 database probe disabled on the gateway
- 23:55 node count nominal, incident closed

## Contributing factors
During a traffic spike, health-check probes that query the database could not acquire connections from pgbouncer-main because the connection pool was exhausted. Probes failed, the gateway ejected healthy nodes, and load shifted onto the remaining nodes.

## Action taken
Disabled the database check in the gateway health probe.

## Follow-up
Third team affected by pgbouncer-main this year. [[PLT-449]] still open.
