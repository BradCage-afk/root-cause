# INC-244 — Order writes blocked by schema migration

Order writes stalled for 30 minutes during a daytime schema migration.

## Timeline
- 13:10 migration starts
- 13:12 order write latency climbs
- 13:40 migration completes

## Contributing factors
A schema migration took an exclusive lock on the orders table for 18 minutes. Writes queued behind the lock. The migration had never been tested against production-sized tables.

## Action taken
Waited for the migration to finish. Migrations now require a size-matched rehearsal.
