# INC-226 — Autoscaler flapping

Pods scaling up and down every minute.

## Timeline
- 14:20 alert fired
- 15:10 restored, incident closed

## Contributing factors
Scale-up and scale-down thresholds were set 2% apart with no stabilisation window, so the autoscaler oscillated.

## Action taken
Added a five-minute stabilisation window.
