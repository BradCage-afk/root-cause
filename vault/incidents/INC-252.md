# INC-252 — Nightly report job ran twice

Duplicate reports sent to partners.

## Timeline
- 02:05 alert fired
- 03:00 restored, incident closed

## Contributing factors
Clock skew on one scheduler node made it claim a job that another node had already started, because the job lock used local timestamps.

## Action taken
Job locks now use the database clock.
